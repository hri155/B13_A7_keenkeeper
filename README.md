Project Name: KeenKeeper

Description: KeenKeeper is a friendship management web application that helps users keep track of meaningful relationships, monitor communication goals, and maintain regular contact with friends.

Features:

Home Page:

Responsive navigation bar with active route highlighting
Banner section with summary statistics
Friend cards displaying:
Profile picture
Name
Days since contact
Tags
Status indicator

Friend Details Page:

Detailed friend profile information
Relationship goal section
Quick Check-In actions:
Call
Text
Video
Toast notifications for interactions
Timeline entries created automatically

Timeline Page:

Displays all logged interactions
Filter interactions by: Call,Text,Video
Persistent timeline data using localStorage

Friendship Analytics:

Pie chart visualization using Recharts
Displays interaction counts by type: Call,Text,Video

Additional Features:

Custom 404 page
Loading spinner while fetching friend data
Fully responsive design
Local storage persistence
Dynamic routing with Next.js

Technologies Used:

Next.js (App Router)
React.js
Tailwind CSS
Recharts
Lucide React Icons
Sonner (Toast Notifications)
